# Мониторинг работы датчиковой аппаратуры металлургического агрегата

Практическая работа №3 «Веб-приложения реального времени». За основу взят проект
из практической работы №2.

## Постановка задачи

Веб-приложение в реальном времени показывает показания датчиков, установленных
на оборудовании металлургических агрегатов. Обмен данными между клиентом и сервером
двусторонний и выполняется через ASP.NET Core SignalR. Сервисы аутентификации
и авторизации разделяют пользователей по ролям: гость, пользователь и администратор.

Гость может выбрать производственную площадку (1-й метод обработки сообщений
от клиента) и просматривать количество пользователей онлайн (1-й метод отправки
сообщений клиентам — всем), новые показания датчиков площадки (2-й метод — группе
площадки) и тревоги о выходе значений за границы нормы (3-й метод — всем).
Пользователь в дополнение к функциям гостя может передавать показания контрольных
замеров (2-й метод обработки сообщений от клиента) и получает подтверждение
сохранения (метод отправки отправителю). Администратор в дополнение к функциям
пользователя может квитировать тревоги (3-й метод обработки сообщений от клиента)
и включать или выключать имитатор датчиков (4-й метод). Показания датчиков
и отметки о квитировании сохраняются в базе данных.

## Что сделано

- подключён SignalR, добавлен хаб мониторинга `MonitoringHub`;
- добавлены модели датчика и показания датчика, миграция базы данных;
- добавлен имитатор датчиков, который периодически формирует показания;
- добавлены страница мониторинга и справочник датчиков.

## Запуск

Открыть `ProductCatalogApp.slnx` в Visual Studio и запустить проект. База данных,
учётная запись администратора и демонстрационные датчики создаются при первом запуске.
